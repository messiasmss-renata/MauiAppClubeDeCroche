## 🧶 Clube do Crochê – Cadastro de Eventos

Aplicativo desenvolvido em .NET MAUI com C#, que permite realizar inscrições em eventos, selecionar dias de participação e calcular automaticamente os valores individuais e totais. O projeto utiliza Model, BindingContext, DateTime e TimeSpan para gerenciamento dos dados e apresentação do resumo da inscrição.
